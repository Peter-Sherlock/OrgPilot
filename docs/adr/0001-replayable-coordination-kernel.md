# ADR-0001：先构建可回放协调内核

- 状态：Accepted
- 日期：2026-08-26

## 背景

初始设计同时包含飞书接入、组织状态、Agent Loop、审批、评测和真实写入。如果先接
平台，项目价值可能被 API 适配工作掩盖，也无法判断状态恢复和协调机制本身是否有效。

## 决策

P0 使用版本化不可变事件、进程内 append-only log、确定性投影、邻接表依赖传播、
Coordination Case 和规则优先 Policy Engine。外部平台、数据库和 LLM 均通过后续
接口接入，不能改变 P0 的领域语义。

## 后果

正面影响：

- 场景可重复回放；
- 状态和动作均可追溯；
- 平台故障不会阻塞核心机制验证；
- benchmark 可以直接比较结构化结果。

代价与限制：

- 目前没有持久化、并发和外部执行；
- 自然语言理解准确率尚未被验证；
- 场景环境不能代表真实团队行为。

在 P0 Ground Truth 无法稳定通过之前，不开始飞书接入。
