# 用户访谈提纲：跨职能项目团队的 PM / 组长

配合 [`requirements-analysis.md`](requirements-analysis.md) 使用。每个问题后面的 `[H?]` / `[R?]` 对应需求分析里要验证的假设和需求。

## 原则

- **问过去发生的具体事，不问将来会不会。**"你会用这样的工具吗"几乎所有人都会说会，没有信息量；"上一次延期是怎么发现的"才有。
- **不推销。**前 30 分钟不提 OrgPilot。对方一旦知道你在做什么，回答就会往你想听的方向偏。
- **追问细节。**听到"经常""挺麻烦"时追一句："最近一次是什么时候？具体怎么回事？花了多久？"
- **记原话。**结论可以之后再提炼，原话当场记。

## 找谁

- 在跨职能项目里负责协调的人：项目经理、产品经理兼项目负责人、技术负责人兼项目负责人；
- 最近 3 个月带过至少一个跨职能项目；
- 团队 5–20 人；
- 尽量来自不同公司或不同部门，避免 5 个人都说同一个项目。

## 流程（30–45 分钟）

### 0. 开场（2 分钟）

- 说明目的：想了解团队协作实际是怎么做的，不是推销产品；
- 征得同意：能不能录音或记笔记；记录会匿名，不涉及公司机密。

### 1. 背景（5 分钟）

- 你们团队有哪些角色、多少人？一个项目一般多长？
- 任务和进度记在哪里？用什么工具？

### 2. 最近一次出问题的项目（10 分钟）

请对方讲最近一次延期或出问题的项目，按时间线展开：

- 问题最早是谁知道的？你是什么时候知道的？中间隔了多久？`[H2]`
- 你是怎么知道的：站会、私聊、看工具，还是别人告诉你的？
- 知道以后你做了什么？找了哪些人？前后花了多长时间？`[R2]`
- 如果能早点知道，结果会有什么不同？

### 3. 日常同步（8 分钟）

- 上周你花在"了解大家进度"上的时间大概多少？分别是什么形式？`[H1]`
- 工具里的状态和你私下问到的真实情况，最近一次差别有多大？能举个例子吗？`[H3]`
- 你私聊问进度时，大家一般多久回？回得准吗？什么情况下不回？`[H4]`
- 你们开站会吗？多久一次、多长时间？哪部分最浪费时间？`[R4]`

### 4. 交接与依赖（6 分钟）

- 最近一次"有人在等别人"是什么情况？等了多久？最后是怎么解决的？`[R1]`
- 设计稿或提测时间变了，下游是怎么知道的？有没有人不知道而按旧计划干？`[R5]`
- 有人请假或被临时抽走时，他的任务怎么处理？`[R6]`

### 5. 承诺与会议（5 分钟）

- 最近一次会上说好的事后来没人跟进，是什么情况？后来是怎么发现的？`[H5]` `[R7]`
- 评审会或周会的结论记在哪？会后谁负责跟进？

### 6. 汇报（3 分钟）

- 你多久写一次周报或项目报告？一次花多久？最麻烦的是哪一部分？`[R8]`
- 有没有被领导问过"为什么改期"而一时答不上来？`[R9]`

### 7. 对 AI 和机器人的态度（5 分钟，放最后，避免引导前面的回答）

- 你们用过飞书项目、Jira 这类工具里的 AI 功能吗？用了哪些？为什么用或不用？
- 如果有个机器人私聊团队成员问进度，你觉得大家会怎么反应？什么情况下会反感？`[H4]`
- 让机器人读群聊，你能接受吗？需要什么限制？`[H6]`
- 在你们企业装一个飞书自建应用，需要谁批准？难不难？`[H7]`

### 8. 收尾（2 分钟）

- 协作上还有什么最头疼、但我没问到的？
- 能不能介绍一位同样带项目的人？
- 之后如果有试用版本，愿意试吗？

## 记录表（每次访谈当天填完）

| 字段 | 内容 |
|---|---|
| 受访者编号 | P1–P5（不记真名） |
| 角色 / 团队规模 / 行业 | |
| 日期 | |
| 关键原话 | 3–5 条，带上下文 |
| 量化信息 | 例：追进度每周约 X 小时；最近一次阻塞约 X 天后才知道 |
| H1–H7 判断 | 每条写"支持 / 反对 / 不确定"，并写依据是哪段经历 |
| 意外发现 | 事先没想到的痛点或做法 |
| 能否试点 | 是 / 否，需要什么条件 |

## 汇总方法

1. 全部访谈完成后，画一张"假设 × 受访者"矩阵，每格填支持 / 反对 / 不确定；
2. 至少 3 位受访者给出支持性的**具体经历**，这条假设才算成立；
3. 只有成立的痛点才能进 v1 的 P0；
4. 意外发现单独列出来，它们往往比预设的假设更有价值。

## 隐私

- 记录只用匿名编号，不记录能识别出个人或公司的信息；
- 不记录项目机密，必要时把原话改写去标识；
- 录音只用于整理笔记，整理完删除。
