## 预算口径

- 在线输入按完整 UTF-8 请求和协议余量预检；输出上限传到真实请求，供应方 actual usage 用于结算。
- 未知或缺失用量不记零；未尝试的最终预留可释放，已尝试但结果未知的请求保留最坏数额。
- 单价是接入者配置的保守预算价格，不是代码猜测的供应商报价，也不等同于最终账单。
- 四类工具共享累计调用、证据片段和正文字符额度；重复返回与缓存命中仍计消耗。
- 会话、步骤与预算属于资料追踪；不追加 OrgEvent，不运行协调轮次，不改 Case、审批或原待答状态。
